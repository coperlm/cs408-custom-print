## Git 归档方式

原始 PDF 保留在上述本地路径，不复制进仓库：它约 127 MB，超过常见 Git 远端的 100 MB 单文件限制。`408真题PDF原始页/` 是从 PDF 内嵌图像直接提取的 154 张 JPEG 页面，总大小约 122 MB；单页文件均低于远端单文件限制，可用于追溯和后续裁切。

页面文件名中的数字是 PDF 页码，从 `page-1.jpg` 到 `page-154.jpg`。PDF 印刷页码可能与文件页码相差封面、目录等页数，索引应以文件页码字段为准。

提取命令：

```sh
mkdir -p '源资料/408真题PDF原始页'
pdfimages -j \
  '/home/coper/桌面/solveworse/【无间隔】计算机408【09-26年】真题做题本10.15.pdf' \
  /tmp/page
for f in /tmp/page-*.jpg; do
  n=${f##*/}; n=${n#page-}; n=${n%.jpg}
  cp "$f" "源资料/408真题PDF原始页/page-$((10#$n + 1)).jpg"
done
rm -f /tmp/page-*.jpg
```

不同版本的 `pdfimages` 可能使用从零开始的页码序号；上面的循环将其转换为从 1 开始的文件名。抽取前应先确认输出为 154 张页面。
